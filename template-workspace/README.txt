This folder is ONE BOOK.

  loom/        the writing: projects, stories, pools, traces, the job queue
  extractor/   the scanner: chapters it read, toplists, examples
  logs/        the server's output

Everything the app writes while you work lands inside here and nowhere else,
so you can copy this folder to another disk or another machine and open it
there. Move it, rename it, back it up with a file copy.

It was laid down from template-workspace/, which
tools/build_template.sh mints. It starts empty on purpose:
no demo, no sample chapters, nothing to delete before you begin.
